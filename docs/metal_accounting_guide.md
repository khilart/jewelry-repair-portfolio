# Руководство пользователя: Учёт металла

## Обзор

Модуль учёта металла ведёт баланс драгоценных металлов в разрезе сплавов и хранилищ. Основные контуры:

- **Хранилища** — где физически находится металл (сейф менеджера, рабочее место мастера)
- **Движения** — приход, списание, перемещение, переплавка
- **Потери** — возвратные (стружка, опилки) и безвозвратные (пыль, угар)
- **Автоматический расчёт** — из заказов ремонта

---

## Первоначальная настройка

### 1. Справочник металлов и сплавов

`Jewelry Metal Accounting → Catalogs → Metals`

Создайте металл (например, Золото), внутри карточки — сплавы (Au 585, Au 750 и т.д.) с указанием пробы (`purity`). Проба используется для пересчёта веса сплава в вес чистого металла в отчётах.

### 2. Хранилища

`Jewelry Metal Accounting → Catalogs → Metal Storages`

Создайте хранилище для каждого физического места хранения:

| Хранилище | Код | Ответственный |
|-----------|-----|---------------|
| Сейф менеджера | SAFE | Менеджер |
| Рабочее место: Иван | WS-IVAN | Мастер Иван |
| Рабочее место: Мария | WS-MARIA | Мастер Мария |

### 3. Хранилище на исполнителе

`Jewelry Production → Catalogs → Executors` → открыть исполнителя → поле **Metal Storage**

Каждому исполнителю (мастеру) нужно привязать хранилище. Это хранилище используется при автоматическом расчёте потерь из заказов.

### 4. Коэффициенты потерь на операциях

`Jewelry Production → Catalogs → Operations` → открыть операцию → блок **Metal Loss Coefficients**

| Поле | Описание |
|------|----------|
| Recoverable Loss % | % возвратных потерь (стружка, опилки, крапаны) |
| Irrecoverable Loss % | % безвозвратных потерь (пыль, угар при пайке) |

Пример настройки:

| Операция | Возвратные % | Безвозвратные % |
|----------|-------------|-----------------|
| Полировка | 0.10 | 0.20 |
| Закрепка | 0.05 | 0.00 |
| Изменение размера | 0.30 | 0.10 |
| Пайка | 0.10 | 0.30 |

Проценты считаются от веса изделия при приёмке (`received_weight`).

## Ручное создание движений металла

`Jewelry Metal Accounting → Metal Documents → New`

Типы документов:

| Тип | Когда использовать |
|-----|--------------------|
| Receipt (Приход) | Получение металла от поставщика или клиента |
| Transfer (Перемещение) | Передача между хранилищами |
| Write-Off (Списание) | Расход металла мастерской |
| Remelt (Переплавка) | Переплавка лома |

После заполнения нажмите **Post** — движение попадёт в баланс.

## Автоматический расчёт металла из заказа

Используется для фиксации потерь и расхода металла по каждому заказу ремонта.

### Шаг 1 — Взвесить и заполнить веса

В форме заказа ремонта:
- **Received Weight** — вес изделия при приёмке
- **Delivered Weight** — вес при выдаче клиенту (заполняется перед нажатием кнопки)
- **Alloy** — сплав изделия (обязательно)

### Шаг 2 — Мастер отмечает добавленный металл

В форме операции (мобильная или десктопная) мастер ставит чекбокс **Metal Was Added** если в ходе операции добавлялся металл — пайка, вставка заготовки при изменении размера и т.п.

### Шаг 3 — Нажать «Calculate Metal»

Кнопка появляется на форме заказа когда заполнен `Delivered Weight`.

Что происходит при нажатии:

1. По каждой незакрытой операции рассчитываются потери:
   - `возвратные = received_weight × loss_recoverable_percent / 100`
   - `безвозвратные = received_weight × loss_irrecoverable_percent / 100`
2. Создаются записи в Loss Register на хранилище исполнителя каждой операции
3. Если хотя бы одна операция отмечена **Metal Was Added**:
   - Рассчитывается количество добавленного металла по формуле баланса:
     ```
     металл_добавлен = (выдан - получен - вес_камней) + все_потери
     ```
   - Создаётся документ списания (Write-Off) из хранилища соответствующего мастера

После расчёта заказ помечается **Metal Calculated** и кнопка скрывается.

### Сброс расчёта (только менеджер)

Кнопка **Reset Calculation** доступна менеджеру. При нажатии:
- Удаляются все рассчитанные потери из Loss Register
- Отменяется документ списания добавленного металла
- Флаг `metal_calculated` снимается — можно пересчитать

## Loss Register (Реестр потерь)

`Jewelry Metal Accounting → Loss Register`

Показывает все зафиксированные потери. Типы записей:

| Тип | Откуда |
|-----|--------|
| Material Loss | Автоматически при завершении операции с материалами |
| Recoverable Loss | Из расчёта по заказу (стружка, опилки) |
| Irrecoverable Loss | Из расчёта по заказу (пыль, угар) |

**Полезные группировки** (кнопка Group By):
- По типу потерь — сколько возвратных vs безвозвратных
- По хранилищу — сколько накопилось у каждого мастера
- По сплаву — в разрезе Au 585 / Au 750 и т.д.
- По месяцу — динамика за период

---

## Ведомость остатков (Stock Statement)

`Jewelry Metal Accounting → Stock Statement`

Показывает остатки и движения за выбранный период в разрезе хранилищ и сплавов. Используется для сверки физического металла с системой.

Параметры:
- **Date From / Date To** — период
- **Metal** — фильтр по металлу (опционально)

В отчёте:
- Остаток на начало периода
- Приход / Расход за период
- Остаток на конец
- Детализация движений при раскрытии строки (drill-down)

## Частые вопросы

**Кнопка Calculate Metal не появляется**
→ Заполните поле Delivered Weight в заказе.

**Ошибка «no metal storage set on executor»**
→ Откройте `Catalogs → Executors`, найдите исполнителя операции и укажите ему Metal Storage.

**Предупреждение «calculated amount is X g — no writeoff document was created»**
→ Математика не сходится: delivered weight меньше received weight + вес камней + потери. Проверьте веса приёмки и выдачи.

**Нужно пересчитать — расчёт уже сделан**
→ Нажмите Reset Calculation (доступно менеджеру), затем Calculate Metal заново.
