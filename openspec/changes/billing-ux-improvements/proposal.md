# Proposal: Billing UX Improvements

## Intent

Улучшить контроль процесса биллинга: дашборд ожидающих клиентов, улучшенные фильтры и группировки в списке заказов.

Исходная спецификация перенесена в `archive/BILLING_UX_SPEC.md`.

## Scope

В scope:
1. **Автозаполнение периода в форме батча** — при выборе клиента подставляет `date_from` = день после последнего батча, `date_to` = сегодня
2. **Дашборд Pending Billing** — список клиентов с невыставленными заказами
3. **Фильтры по payment_status** в AR-отчёте и списке заказов (unbilled / unpaid / partial / paid)
4. **Group By** по billing_date и delivery_date (месяц) в списке заказов

Вне scope:
- Изменение модели биллинга
- Изменение логики выбора заказов через `line_ids`

## Approach

Работа в рамках существующих модулей `jewelry_repair_billing`. Дашборд — отдельный `ir.actions.act_window` или QWeb-отчёт. Фильтры и группировки — расширение XML-вьюх.

## Приоритет

Средний. Функционально биллинг работает, это UX-улучшения для приёмщиков.
