# Delta for Repair / Billing

## ADDED Requirements

### Requirement: Автозаполнение периода при выборе клиента

При выборе клиента в батче биллинга период заполняется автоматически.

#### Scenario: Автозаполнение дат

- GIVEN форма биллинг-батча без заполненных дат
- WHEN пользователь выбирает клиента
- THEN `date_from` = дата следующего дня после последнего подтверждённого батча для этого клиента
- AND `date_to` = сегодня

---

### Requirement: Дашборд Pending Billing

Сводный список клиентов, у которых есть невыставленные выданные заказы.

#### Scenario: Список клиентов в дашборде

- GIVEN открыт дашборд Pending Billing
- WHEN нет примерённых фильтров
- THEN отображаются все клиенты с `delivered + unbilled` заказами
- AND для каждого клиента: последний биллинг, количество заказов, сумма

#### Scenario: Быстрое создание батча из дашборда

- GIVEN клиент в дашборде
- WHEN пользователь нажимает кнопку создания батча
- THEN открывается форма нового батча с предзаполненным клиентом и периодом

---

### Requirement: Фильтры по payment_status

#### Scenario: Фильтр unbilled

- GIVEN список заказов
- WHEN применяется фильтр "Unbilled"
- THEN отображаются только delivered заказы без биллинга

#### Scenario: Группировка по месяцу биллинга

- GIVEN список заказов
- WHEN применяется Group By "Billing Date (Month)"
- THEN заказы группируются по месяцу `billing_date`
